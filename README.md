# ¡Bienvenido/a! 👋

Hola a todos, soy Jericó. En este perfil, encontrarán algunos de los proyectos que he desarrollado durante mi formación académica, donde he podido poner en práctica mis conocimientos y seguir aprendiendo.

## 🖥️ Proyectos 

1. **[TFG - Diseño e implementación de una aplicación web para la anonimización automática de documentos mediante modelos de lenguaje](https://github.com/JericoLuzardoMiranda/TFG-Anonimizador)**

    - Desarrollo de una aplicación web para detectar y anonimizar datos sensibles en documentos. Utiliza expresiones regulares y listas de validación para identificar información personal y aplica técnicas de anonimización. Incorpora IA generativa como apoyo para analizar casos complejos.

2. **[JEDAPA Aplicación Fórmula 1](https://github.com/JericoLuzardoMiranda/PAMN-Jedapa-App)**

    - Aplicación móvil centrada en el mundo de la Fórmula 1, que reúne noticias, información sobre equipos y pilotos, clasificaciones y calendario de carreras en una única plataforma. Incluye una funcionalidad competitiva para que los usuarios pongan a prueba sus conocimientos y compitan con amigos.

3. **[Eterna of Jade](https://github.com/JericoLuzardoMiranda/IG-Trabajo-Unity)**

    - Videojuego de mundo abierto desarrollado en Unity que permite explorar libremente un amplio mapa mediante controles intuitivos de teclado, que ofrece una experiencia interactiva a través de diversos paisajes.

4. **[Sistema Planetario](https://github.com/JericoLuzardoMiranda/IG-Sistema-Planetario)**

    - Visualización interactiva del Sistema Solar desarrollada con Three.js que permite explorar los planetas, sus lunas y otros cuerpos celestes, observar sus movimientos orbitales y consultar información detallada sobre cada planeta. Incluye funcionalidades adicionales como el control de una nave espacial, la visualización de datos meteorológicos de distintas ciudades y elementos dinámicos como las texturas diurnas y nocturnas de la Tierra y un satélite en órbita.

Pueden consultar mis repositorios para conocer más sobre mis proyectos.
